Scare Tactics

React Native / AI

I went on an AI sabbatical - designing and building an app from scratch to test what's actually possible with the tools available. This is Scare Tactics - an Accountability Coach that preys on your worst fears to achieve your goals.

Built with an toolchain of: Claude for code gen and logic, Cursor as the IDE, React Native + Expo for the app framework, ElevenLabs for voice, MidJourney for images and Figma for design - wired together with MCP so Claude could read the frames directly.

Tech

Typescript, React Native, Expo, ElevenLabs, Figma,
Claude, Cursor, Midjourney, MCP
